# Declaración de uso de inteligencia artificial

**Proyecto:** Sistema multiagente de moderación de chat (JADE + Weka)  
**Asignatura:** Sistemas Inteligentes — UPM

---

## Herramientas utilizadas

Durante el desarrollo de este proyecto se han utilizado asistentes de IA generativa (p. ej. Cursor / modelos de lenguaje) como **apoyo**, no como sustituto del trabajo del grupo.

## Usos concretos

| Área | Uso de IA | Supervisión del grupo |
|------|-----------|------------------------|
| Diseño inicial | Sugerencias de arquitectura multiagente y checklist del enunciado | Revisado y adaptado al dominio del chat |
| Código JADE | Plantillas de comportamientos, registro DF, filtros ACL | Probado, depurado y entendido por el grupo |
| Documentación | Borradores de README y memoria | Revisados; datos de grupo y capturas aportados por alumnos |
| Weka / ML | Recordatorio de API Weka (`FilteredClassifier`, J48) | Parámetros y dataset definidos por el grupo |

## Compromiso del grupo

- El **diseño funcional**, la **defensa oral** y las **pruebas** son responsabilidad de los miembros del grupo.
- Cualquier fragmento generado con IA ha sido **revisado**, **compilado** y **ejecutado** localmente antes de la entrega.
- El grupo puede **explicar** cada agente, comportamiento, mensaje ACL y paso del pipeline Weka sin depender de la herramienta.
